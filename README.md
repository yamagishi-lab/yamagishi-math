# yamagishi-math

Machine-checked statements from the papers of Yuuki Yamagishi (山岸勇輝), written in Lean 4 with Mathlib.
The repository covers 134 papers: 16 whose statements are checked as the papers state them, and 118 for which a more general statement is proved here than the paper currently proves (the papers show these with numbers or tables; see the second table). For 33 papers only the core of the statement is formalized; this is marked "core only": Papers 36, 37, 59, 141, 202, 205, 208, 327, 340, 373, 391, 412, 488, 579, 635, 638, 640, 674, 688, 696, 824, 908, 928, 935, 939, 945, 954, 995, 1064, 1081, 1098 and 1101 in the second table, and Paper 1105 in the first.

山岸勇輝の論文の定理と法則のうち、数学の中身を Lean 4（Mathlib）で書き、機械に証明を確かめさせたものです。134 本の論文を扱い、16 本は原稿の言明のとおりに、118 本は原稿がいまは数値や表で示している事を、より一般の形の定理として証明しています（二つ目の表）。そのうち 33 本は芯だけです（二つ目の表の論文36・37・59・141・202・205・208・327・340・373・391・412・488・579・635・638・640・674・688・696・824・908・928・935・939・945・954・995・1064・1081・1098・1101 の 32 本と、一つ目の表の論文1105）。日本語の説明は下にあります。

- Author: Yuuki Yamagishi (ORCID [0009-0006-8587-3450](https://orcid.org/0009-0006-8587-3450))
- Papers: <https://www.yamagishiyuuki.com/yoi/>
- Lean `v4.37.0-rc1`, Mathlib `v4.37.0-rc1` (see `lean-toolchain` and `lake-manifest.json`)
- No `sorry`, no extra axioms, no `native_decide`. The main theorems depend only on the three standard axioms (`propext`, `Classical.choice`, `Quot.sound`).
- The Lean code was written with the assistance of AI (Claude by Anthropic). The statements come from the author's papers (for the second table, the general statements were formulated here from the claims in the papers), and the author is responsible for the content.

## What is not checked

- Lean checks the statements as written in Lean. Whether a Lean statement says the same thing as the sentence in a paper is for a human reader to compare; the correspondence table is there for that.
- Only the mathematical content is formalized (exponent bookkeeping, integrals, "if and only if" statements). The physical readings in the papers, such as "this 4π is a solid angle" or "this 4π is a convention", are outside the formalization.
- For the papers in the second table, the Lean statement is more general than what the paper proves at present. ## How to check it yourself

Install Lean with [elan](https://lean-lang.org/install/), then:

```
lake exe cache get
lake build
```

`lake build` finishes without errors when every theorem in the repository has been checked.
